Conocimientos Adquiridos

Escuela Técnica N°35 DE 18

Durante mi formación secundaria adquirí conocimientos en desarrollo web, bases de datos y programación. Aprendí a utilizar HTML y CSS para el diseño de páginas web estáticas, comprendiendo la estructura, estilos y organización de interfaces. Además, incorporé conceptos básicos de programación en lenguajes como JavaScript, C++ y Assembler, lo que me permitió desarrollar el pensamiento lógico y la resolución de problemas.

En quinto año profundicé en bases de datos, aprendiendo conceptos fundamentales como claves primarias y foráneas, modelado de datos y normalización. También trabajé con SQL, realizando consultas para la manipulación, administración y recuperación de información. Utilizamos Microsoft Visual Studio para desarrollar aplicaciones simples, integrando bases de datos con interfaces funcionales.

Como proyecto integrador, desarrollé junto a un equipo un sistema de control de stock para un local de ropa. En este proyecto aplicamos modelado de base de datos en función de los requerimientos del cliente, incluyendo gestión de productos, control de inventario, emisión de facturas y remitos. Implementamos la aplicación en Visual Studio, conectándola con la base de datos mediante consultas SQL, logrando una integración entre la lógica del sistema y la persistencia de datos. Además, elaboramos una guía de usuario para facilitar la utilización del software.

En sexto año incorporé conocimientos en Java, abordando desde conceptos básicos hasta Programación Orientada a Objetos (POO), interfaces y manejo de hilos. Trabajé en el entorno de desarrollo Eclipse y utilicé LibGDX, un framework para el desarrollo de videojuegos multiplataforma.

Como proyecto final, desarrollé junto a un equipo un videojuego multijugador en red. Este proyecto implicó la integración de múltiples tecnologías y herramientas, así como el aprendizaje autónomo para resolver problemas técnicos no vistos en clase. A pesar de las dificultades, logramos completar el proyecto, destacando la capacidad de trabajo en equipo, la perseverancia y la búsqueda de soluciones mediante investigación y aprendizaje continuo.
